A desktop-friendly notepad for notes, checklists, and drafts. Everything stays local in your browser unless you import or export a file.

Local-first workflow

The current note autosaves in this browser. Use Import file to open a `.md` or `.txt` file and Export .md when you want a copy on disk.

Useful shortcuts

  • Ctrl+B bold
  • Ctrl+I italic
  • Ctrl+1/2/3 headings
  • Ctrl+Shift+C code block
  • Ctrl+K link

Safety

Preview output is sanitized by default. Turn on trusted HTML only when you fully trust the note content.
